# Lisa's skills

Reusable agent skills for program management, rollouts, and change management, usable in Claude Code, Cursor, and other Agent Skills compatible tools.

| Name | What it does | Link |
| --- | --- | --- |
| internal-golive-gtm-change-planner | Plans or revises an internal software rollout as one integrated plan: go-live readiness, internal go-to-market, and change management, plus machine-readable plan data. AI is a conditional add-on. | [internal-golive-gtm-change-planner](./internal-golive-gtm-change-planner/README.md) |

## How to use

- **Claude Code:** copy the folder into `.claude/skills/` in a project or `~/.claude/skills/`.
- **Cursor:** copy the folder into the project's skills location, or reference `SKILL.md`.

Examples use EXAMPLE data.
